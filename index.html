💡 시험 직전 1분 암기 공식

1. 중국 왕조 & 북방 민족

• 기본 흐름: 송 → 원 → 명 → 청
• 송 압박 북방 민족: 거-탕-여 (거란·요 → 탕구트·서하 → 여진·금)
• 청 전성기 3황제: 강-옹-건 (강희제 → 옹정제 → 건륭제)

2. 프랑스 혁명 의회 변천 (출제 1순위)

삼 - 국 - 입 - 공 - 총 - 나
(삼부회 → 국민 의회 → 입법 의회 → 국민 공회 → 총재 정부 → 나폴레옹)

3. 중국 근대화 운동 순서

태 - 양 - 변 - 의 - 신
(태평천국 → 양무운동 → 변법자강 → 의화단 → 신해혁명)

4. 일본 막부 정권 순서

가 - 무 - 전 - 에
(가마쿠라 막부 → 무로마치 막부 → 전국 시대 → 에도 막부)

5. 신항로 개척 탐험가

• 포르투갈(동쪽): 디아스(희망봉) → 다가마(인도)
• 에스파냐(서쪽): 콜럼버스(서인도) → 마젤란(세계 일주)

6. 헷갈리는 쌍둥이 개념

• 영국 문서: 권리 청원(1628, 찰스1세) vs 권리 장전(1689, 명예혁명)
• 무굴 황제: 아크바르(지즈야 폐지) vs 아우랑제브(지즈야 부활)
• 대공황 극복: 미국(뉴딜 정책) vs 영국·프랑스(블록 경제)
